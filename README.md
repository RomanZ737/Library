# Library
**REST API для управления электронной библиотекой: книги, авторы, оценки, выдача и возврат книг.**
Проект реализован на Django + Django REST Framework, с JWT-аутентификацией, PostgreSQL, Docker и покрытием тестами >75%.

# Функциональность

*Книги*

    - Создание, редактирование, удаление (только администратор)
    - Список с пагинацией (доступен любому аутентифицированному пользователю)
    - Поиск по названию, автору, аннотации
    - Фильтрация по жанру, автору, статусу аренды
    - Сортировка по названию, дате публикации, средней оценке, количеству оценок


*Авторы*

    - CRUD (изменения — только администратор)
    - Список с пагинацией


*Оценки книг*

    - Пользователь ставит одну оценку на книгу (0–5)
    - Может изменить или удалить свою оценку
    - Чужие оценки недоступны
    - Средняя оценка и количество оценок автоматически пересчитываются


*Выдача книг*

    - Любой аутентифицированный пользователь может взять книгу
    - Срок аренды по умолчанию — 30 дней, максимум 60
    - Возврат книги — только администратор
    - Активная аренда — уникальна на книгу
    - Статус is_rented синхронизируется автоматически

*Пользователи*

    - Регистрация (открытая)
    - Авторизация по email (JWT: access + refresh)
    - Просмотр информации о пользователях
    - Обычный пользователь видит только свой профиль
    - Администратор видит всех

# Роли и права доступа

В проекте три уровня доступа.

*1. Анонимный пользователь (не аутентифицирован)*

Доступно:

    - POST /users/register/ — регистрация
    - POST /users/login/ — получение JWT-пары
    - POST /users/token/refresh/ — обновление access-токена
    - GET /swagger/, GET /redoc/ — документация

    Всё остальное — 401 Unauthorized.

*2. Аутентифицированный пользователь*

Доступно (с JWT в заголовке Authorization: Bearer <access>):

    - Просмотр книг, авторов, жанров
    - Поиск, фильтрация, сортировка книг
    - Создание своей оценки книги
    - Изменение / удаление своей оценки
    - Взятие книги в аренду
    - Просмотр активной аренды книги
    - Просмотр своего профиля и его редактирование

Недоступно:

    - Создание / изменение / удаление книг и авторов
    - Возврат книги
    - Редактирование чужих профилей и чужих оценок

*3. Администратор*

**Администратор** — это пользователь, состоящий в группе «Администраторы» или имеющий флаг is_superuser.

Дополнительно доступно:

    - CRUD книг, авторов
    - Возврат книги (DELETE /books/<book_id>/rent/)
    - Просмотр всех пользователей

    Права реализованы через кастомный IsAdminGroup (users/permissions.py), который проверяет is_superuser или наличие группы.
    *Примечание*: Флаг is_staff отвечает только за доступ к Django-админке (/admin/) и не влияет на права в API.


# Быстрый старт: Docker
*Требования*

    Docker
    Docker Compose (v2)

*Шаги*
- Клонировать репозиторий:
    git clone https://github.com/RomanZ737/Library.git
    cd Library
- Создать .env на основе шаблона:
  cp .env.sample .env
- Отредактировать .env (см. Переменные окружения). Минимум — задать SECRET_KEY и пароль для PostgreSQL.
- Собрать и запустить:
  docker compose up --build

*Приложение доступно:*

    API: http://localhost:8000/
    Swagger: http://localhost:8000/swagger/
    ReDoc: http://localhost:8000/redoc/
    Django admin: http://localhost:8000/admin/

*Остановка*
- docker compose down

# Наполнение базы тестовыми данными
В проекте есть management-команда add_data, которая создаёт авторов, книги и пользователей для тестирования.

*Запуск*
Через Docker:
 - docker compose exec web python manage.py add_data
Локально:
 - python manage.py add_data
Что создаётся:
- 10 авторов (случайные имена через Faker, локаль ru_RU)
- 20 книг (случайные жанры, аннотации, даты публикации)
- 5 пользователей с email'ами user1@example.com … user5@example.com и паролем testpass123

# Основные эндпоинты
*Пользователи*
Метод	    URL	Права	            Описание
POST	    /users/register/	    Аноним	Регистрация
POST	    /users/login/	        Аноним	Получение JWT
POST	    /users/token/refresh/	Аноним	Обновление access-токена
GET	        /users/users/	        Аутентифицированный	Список пользователей (для админа — все, для остальных — только свой)
GET/PATCH	/users/users/<id>/	    Владелец	Профиль пользователя

*Книги*
Метод	    URL	Права	            Описание
GET	        /books/	                Аутентифицированный	Список с пагинацией, поиском, фильтрацией
POST	    /books/	                Админ	Создание книги
GET	        /books/<id>/	        Аутентифицированный	Детали книги
PUT/PATCH	/books/<id>/	        Админ	Редактирование
DELETE	    /books/<id>/	        Админ	Удаление

*Query-параметры списка книг:*

    search= — поиск по названию, автору, аннотации
    genre= — фильтр по жанру (FICTION, FANTASY, …)
    is_rented= — true / false
    author= — id автора
    ordering= — name, -total_mark, release_date, …
    page=, page_size= — пагинация

*Авторы*
Метод	        URL	            Права
GET	            /authors/	    Аутентифицированный
POST	        /authors/	    Админ
GET	            /authors/<id>/	Аутентифицированный
PUT/PATCH	    /authors/<id>/	Админ
DELETE	        /authors/<id>/	Админ


*Оценки*
Метод	        URL	Права	                Описание
POST	        /books/marks/	            Аутентифицированный	Поставить оценку
PATCH	        /books/marks/update/<id>/	Владелец оценки	Изменить свою оценку
DELETE	        /books/marks/delete/<id>/	Владелец оценки	Удалить свою оценку

*Тело запроса POST / PATCH:*

{
  "book": 1,
  "mark": 5
}

*Аренда книги*
Метод	        URL	                    Права	                Описание
POST	        /books/<book_id>/rent/	Аутентифицированный	    Взять книгу
GET	            /books/<book_id>/rent/	Аутентифицированный	    Активная аренда книги
DELETE	        /books/<book_id>/rent/	Админ	                Вернуть книгу


*Тело POST:*

{
  "rented_date_end": "2026-11-01",
  "comment": "Опциональный комментарий"
}
